# ImageEase – Image Tools App

ImageEase is a modern, privacy-focused and fully offline Android application built with **Kotlin** and **Jetpack Compose**.

It provides a collection of simple and useful image tools in one clean, modern interface — without requiring an internet connection.

## ✨ Features

- 🖼️ Resize Images
- 📦 Compress Images
- 🔄 Convert Image Formats
- ✂️ Crop Images
- 📄 Create PDFs
- 📜 Processing History
- ⚙️ App Settings
- 🔒 Offline & Privacy-Friendly
- 🎨 Modern Material 3 UI
- 🚀 Built with Jetpack Compose

## 🎨 Design & Development

The UI and visual assets are designed with **Canva** and implemented in **Jetpack Compose**.

This project is also part of a tutorial series covering the process of turning Canva designs into real Android UI using Jetpack Compose.

## 📱 ImageEase

**Resize. Compress. Convert. PDF.**

A simple collection of image tools designed for everyday use.

## 🔐 Privacy

ImageEase is designed to work offline, helping users process their images locally without depending on online services.
